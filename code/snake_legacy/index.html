snake_legacy — characterization tests and two agent diffs

Used by Lecture 27 (Legacy code: code without tests) and Lecture 28 (Deciding what not to read).

Attribution

Part Origin
snake.cpp — the game Written by a student in this course. Source: Heer117/Snake_Game@e15f61a, snake.cpp. Unmodified.
tests/ — the characterization tests Written for this course. Not the student's work, and not in their repository.
agent_diffs/ — two pause features Generated by coding agents for Lecture 28, against the unmodified snake.cpp.

None of the 37 snake games submitted for Lab 1 contains a test.

The tests

The game is untouched. The tests break in from outside:

#define class struct       // Game's members become public...
#define private public     // ...and so do Snake's and Food's
#define main snake_main    // keep the game's main() out of the way
#include "../snake.cpp"
File What it shows Result
first_try_test.cpp a test written to fail, so the failure reports the real value 1 failure: Which is: 12
update_test.cpp five characterization tests for Game::update() 5 pass
agent_tests.cpp the quiz: five passing tests, two of which pin a bug 5 pass

Build and run all three (needs GoogleTest), from tests/:

make                  # first_try_test fails on purpose; the other two pass
make run-update_test  # just one

Run it in GitHub Codespaces

The game needs Linux or macOS (termios.h, unistd.h), so it won't build on Windows directly. Codespaces gives everyone the same Linux machine in the browser.

  1. Open the course repo in Codespaces. The first start takes a few minutes; it installs g++, GoogleTest and Claude Code.

  2. In the terminal:

    cd docs/code/snake_legacy/tests && make

  3. Play the game: cd .. && g++ -std=c++17 -o snake snake.cpp && ./snake (arrows or WASD, Q quits).

A coding agent in the codespace:

Agent How Needs
GitHub Copilot (agent mode) the Chat panel in the codespace's VS Code a Copilot plan; verified students can get Copilot Student free
Claude Code run claude in the terminal, or the Claude Code panel a Claude account or API key

Codespaces usage is free up to a monthly allowance (verified students: 180 core hours, about 90 hours on the default 2-core machine). Stop the codespace when you're done.

The agent diffs

Same request to both: "Press P to pause, P again to resume."

File Extra instruction Diff Existing code touched
runA_plain_prompt.diff none +13 −1 drawBoard, processInput, restart, run, one new field
runB_sprout_prompt.diff new class; change at most one existing line +32 −1 one line in processInput

The five update_test.cpp tests pass on both, because neither run touched update().

Apply one to a copy of the game:

cp snake.cpp /tmp/snake.cpp && cd /tmp && patch -p1 < <path>/agent_diffs/runA_plain_prompt.diff
