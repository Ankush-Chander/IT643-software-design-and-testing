## The tests

The game is untouched. The tests break in from outside:

```cpp
#define class struct       // Game's members become public...
#define private public     // ...and so do Snake's and Food's
#define main snake_main    // keep the game's main() out of the way
#include "../snake.cpp"
```

| File | What it shows | Result |
|---|---|---|
| `first_try_test.cpp` | a test written to fail, so the failure reports the real value | 1 failure: `Which is: 12` |
| `update_test.cpp` | five characterization tests for `Game::update()` | 5 pass |
| `agent_tests.cpp` | the quiz: five passing tests, two of which pin a bug | 5 pass |
| `five_steps_agent_test.cpp` | the 18 tests an agent wrote in steps 3–4 of the five-step run (Lecture 27) | 18 pass |

Build and run all three (needs GoogleTest), from `tests/`:

```bash
make                  # first_try_test fails on purpose; the other two pass
make run-update_test  # just one
```

## Run it in GitHub Codespaces

The game needs Linux or macOS (`termios.h`, `unistd.h`), so it won't build on Windows
directly. Codespaces gives everyone the same Linux machine in the browser.

1. Open [the course repo in Codespaces](https://codespaces.new/Ankush-Chander/IT643-software-design-and-testing).
   The first start takes a few minutes; it installs g++, GoogleTest and Claude Code.
2. In the terminal:

    ```bash
    cd docs/code/snake_legacy/tests && make
    ```

3. Play the game: `cd .. && g++ -std=c++17 -o snake snake.cpp && ./snake` (arrows or WASD, Q quits).

```bash

```
