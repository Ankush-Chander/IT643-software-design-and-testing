# Proposal 6: The Verdict

**Q1 — Solves a solved problem.** Certificate forgery is already handled by digitally signed PDFs + a verification portal (e.g., DigiLocker). Blockchain adds cost, not value.

**Q3 — Nobody uses your chain.** Employers and universities don't run blockchain verifiers, so you build a conventional web portal anyway — **at which point the blockchain is decorative**.
