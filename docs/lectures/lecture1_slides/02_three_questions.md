# The Three Feasibility Questions

| # | Question | What it tests |
|---|----------|---------------|
| **Q1** | Does it contribute to organizational objectives? | *Strategic fit* |
| **Q2** | Can it ship on schedule/budget with current technology? | *Practical feasibility* |
| **Q3** | Can it integrate with existing systems? | *Ecosystem compatibility* |

> A proposal failing any **one** question is a non-starter.
