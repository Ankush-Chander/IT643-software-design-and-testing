Demo: the same refactor, with and without a net

Optional lecture. Runs as a live or pre-recorded demo; students only vote.

Quick recap

  • Predict the blast radius, keep diffs small, read the risky paths

The setup

Plan (5 min): one snake game from the class corpus, no tests. One request to an agent: "clean up the movement code." Same request, run twice.

Agenda

  • Run 1: no tests
  • Run 2: characterization tests first
  • What the tests caught

Run 1: no tests

Plan (15 min). The agent refactors. The diff looks clean, the game runs. Vote: ship it?

Run 2: cover first

Plan (15 min). Ask the agent for characterization tests first, review which ones pin real behaviour, then the same refactor. Which tests fail?

What the tests caught

Plan (10 min). The behaviour Run 1 changed silently. Would anyone have noticed by playing, or by reading the diff?

The rule to keep

Plan (5 min): one line.
