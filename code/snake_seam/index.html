snake_seam — a preprocessing seam, end to end

Used by Lecture 13-14 (Testability and design) and Lecture 15-16 (Test code quality).

Attribution

Part Origin
test.cpp — the game Written by a student in this course. Source: Shiroilt/solo-leveling-chapter-snake-monster@93f9af1, snake/test.cpp. Unmodified.
tests/ — the harness, stubs and CMake Written for this course. Not the student's work, and not present in their repository.

No snake game submitted to this course contains a test. The harness exists to show what testing one costs when the design offers no seam.

What it demonstrates

The game is a single translation unit. The score, the clock and main are all file-scope. There is nothing to pass in, so there is nothing to substitute.

tests/snake_test.cpp breaks in from outside:

#include <gtest/gtest.h>
#define main snake_main       // rename the entry point
#include "../test.cpp"        // swallow the whole translation unit
#undef main
  • Seam — the #include "raylib.h" line inside the game.
  • Enabling point — -I stubs, set by target_include_directories in tests/CMakeLists.txt. It puts tests/stubs/raylib.h ahead of the real library, so GetTime(), IsKeyPressed() and GetRandomValue() resolve to scripted stubs.

Not one line of the game was edited. That is what makes it a seam. The enabling point is a build flag, which is what makes it the worst kind — one binary cannot hold two different clocks.

Build and run

Requires GoogleTest.

cd tests && mkdir -p build && cd build
cmake .. && make
./runTests

Expected: [ PASSED ] 19 tests.

The two exercises in the lectures

Both are mutations of test.cpp. Both are measured, not asserted.

1. The suite is blind to the direction rule. Delete the guard on all four keys:

if(IsKeyPressed(KEY_UP) && (s.direction.y!=1))   ->   if(IsKeyPressed(KEY_UP))

The snake can now reverse into itself. Rebuild: 19 tests still pass.

2. The wall test has a silent tolerance window. cellcount is a configuration constant, currently 25.

cellcount Result
25, 29, 31 19 passed
32 MainLoopHitsRightWallAndResets fails

Nothing breaks at 32 — the snake just runs out of frames before reaching the wall, because the test fixes framesUntilClose = 30. That boundary is chosen by nobody.
